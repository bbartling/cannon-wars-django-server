🪰 Fly Swatter Tutorial

The making of the Fly Swatter game begins with C code, where we design all the game's core mechanics and rules, like how a fly moves around a 2D map, its velocity, and its position. As the game progresses, multiple flies are added to each level to make the game harder, and C efficiently handles all the math and movement dynamics. Since C code cannot run directly in a web browser, a tool called Emscripten is used to convert it into WebAssembly (WASM), which is like super-fast machine code for browsers. WebAssembly allows complex things, like game physics and behaviors, to run much faster than JavaScript alone. In this project, JavaScript works alongside WebAssembly by handling the visual drawings on the canvas, the sounds, the mouse clicks, and controlling when levels end or restart. Even though this Fly Swatter game is simple enough that it could run without WebAssembly, using it now lays a strong foundation for building even bigger and more complex games in the future!


🧩 Core C Code Compiled to WASM

The C code below forms the heart of the Fly Swatter game by defining important constants like MAX_FLIES and using a data structure called a struct to describe each fly. Each fly has X and Y position coordinates and velocity in both directions, making it behave like a little bouncing ball inside the game window. The C program includes functions to create new flies, update their positions as they move, retrieve their coordinates, and attempt a swat by checking if a mouse click is close enough to a fly. When a fly is successfully swatted, it is marked as no longer alive by setting its alive status to false. Later, the JavaScript section will show how all these C functions become accessible inside the browser through WebAssembly, allowing JavaScript to quickly read fly positions, detect collisions, and drive the game's visuals, sound, and timing. Together, the C code and WebAssembly make the Fly Swatter game smooth, efficient, and fun!

    #define MAX_FLIES 100

    typedef struct {
        float x;
        float y;
        float vx;
        float vy;
        bool alive;
    } Fly;

    Fly flies[MAX_FLIES];
    int num_flies = 0;
    int screen_width = 800;
    int screen_height = 600;

    EMSCRIPTEN_KEEPALIVE
    void set_screen_size(int w, int h) {
        screen_width = w;
        screen_height = h;
        printf("Screen size set: %d x %d\n", screen_width, screen_height);
    }


    EMSCRIPTEN_KEEPALIVE
    void create_fly() {
        if (num_flies < MAX_FLIES) {
            flies[num_flies].x = rand() % 800;
            flies[num_flies].y = rand() % 600;
            flies[num_flies].vx = (rand() % 1000 / 500.0f - 1.0f) * 5.0f;
            flies[num_flies].vy = (rand() % 1000 / 500.0f - 1.0f) * 5.0f;
            flies[num_flies].alive = true;
            num_flies++;
        }
    }

    EMSCRIPTEN_KEEPALIVE
    void update_flies() {
        for (int i = 0; i < num_flies; i++) {
            if (flies[i].alive) {
                flies[i].x += flies[i].vx;
                flies[i].y += flies[i].vy;

                if (flies[i].x <= 0 || flies[i].x >= screen_width) flies[i].vx = -flies[i].vx;
                if (flies[i].y <= 0 || flies[i].y >= screen_height) flies[i].vy = -flies[i].vy;

            }
        }
    }

    EMSCRIPTEN_KEEPALIVE
    float get_fly_x(int index) {
        if (index < num_flies) return flies[index].x;
        return -1;
    }

    EMSCRIPTEN_KEEPALIVE
    float get_fly_y(int index) {
        if (index < num_flies) return flies[index].y;
        return -1;
    }

    EMSCRIPTEN_KEEPALIVE
    int is_fly_alive(int index) {
        if (index < num_flies) return flies[index].alive ? 1 : 0;
        return 0;
    }

    EMSCRIPTEN_KEEPALIVE
    int get_num_flies() {
        return num_flies;
    }

    EMSCRIPTEN_KEEPALIVE
    void attempt_swat(float mx, float my) {
        for (int i = 0; i < num_flies; i++) {
            if (flies[i].alive) {
                float dx = flies[i].x - mx;
                float dy = flies[i].y - my;
                if ((dx*dx + dy*dy) < (30.0f * 30.0f)) { // 30 = swat radius
                    flies[i].alive = false;
                }
            }
        }
    }

💻 Core JavaScript Game Code

The JavaScript code, which was developed after the C code, is the part of the Fly Swatter game that allows players to interact with everything on the screen. In general, we want all of the heavy mathematics and background calculations to run in C and WebAssembly because it is much faster than JavaScript. You might notice that all the C functions are accessed through Module.cwrap, which comes from Emscripten, a tool that helps turn C code into WebAssembly so it can run in the browser. The rest of the game is just plain, simple JavaScript. JavaScript defines variables for the C functions, manages the game timer (starting at 20 seconds and subtracting 1 second for each level you pass), and adds one more fly each level to make the game harder. It also tracks your mouse clicks, passing the X and Y coordinates to the C side when you attempt a swat. JavaScript sets up the game canvas, handles sound effects like buzzing, swatting, and level completion, and controls the main game loop. While JavaScript handles the drawing and interaction, C and WebAssembly are busy doing all the heavy lifting with the math and fly movements behind the scenes. This project is a simple example where JavaScript could have handled it alone, but setting it up this way prepares us for bigger, more complex games where combining JavaScript and WebAssembly will really shine!

If you also notice, JavaScript is not a compiled language like C. In C, you must statically assign variables, meaning you have to tell the program exactly what kind of data you are storing ahead of time. C code must be compiled into WebAssembly before it can run in the browser. JavaScript, however, is a scripting language that behaves more like Python, where you don't need to declare the type of a variable beforehand. JavaScript code runs directly in the browser and is interpreted at runtime, meaning it is compiled "just in time" as the page loads. This is why JavaScript is very flexible for building user interfaces, while C is better for doing fast math, movement, and background game logic. The entire Fly Swatter game is then served by a small web app written in Python using Flask, which sends the HTML file, the sound files, the JavaScript files, and the WebAssembly (.wasm) file to your browser, where everything comes together to make the game run locally just for you! 



    function startFlySwatterGame() {
      const setScreenSize = Module.cwrap('set_screen_size', 'void', ['number', 'number']);
      const createFly = Module.cwrap('create_fly', 'void', []);
      const updateFlies = Module.cwrap('update_flies', 'void', []);
      const getNumFlies = Module.cwrap('get_num_flies', 'number', []);
      const getFlyX = Module.cwrap('get_fly_x', 'number', ['number']);
      const getFlyY = Module.cwrap('get_fly_y', 'number', ['number']);
      const isFlyAlive = Module.cwrap('is_fly_alive', 'number', ['number']);
      const attemptSwat = Module.cwrap('attempt_swat', 'void', ['number', 'number']);

      const startingTime = 20;
      const swatSound = document.getElementById('swatSound');
      const flySound = document.getElementById('flySound');
      const winSound = document.getElementById('winSound');

      let canvas = document.getElementById('gameCanvas');
      let ctx = canvas.getContext('2d');

      let canvasW, canvasH;
      let mouseX = 0;
      let mouseY = 0;
      let mouseClicked = false;
      let flySoundStarted = false;
      let level = 1;
      let gameTime = Math.max(5, startingTime - (level - 1));
      let gameOver = false;

      function init() {
        canvas.width = document.body.clientWidth;
        canvas.height = document.body.clientHeight;
        canvasW = canvas.width;
        canvasH = canvas.height;
        setScreenSize(canvasW, canvasH);

        createFly(); // Create 1 fly

        window.addEventListener('resize', () => {
          canvas.width = document.body.clientWidth;
          canvas.height = document.body.clientHeight;
          canvasW = canvas.width;
          canvasH = canvas.height;
          setScreenSize(canvasW, canvasH);
        });

        canvas.addEventListener('mousedown', (event) => {
          mouseX = event.clientX;
          mouseY = event.clientY;
          mouseClicked = true;

          if (!flySoundStarted) {
            flySound.currentTime = 0;
            flySound.play().then(() => {
              console.log("y buzzing sound started!");
            }).catch(err => {
              console.error("y buzzing sound failed:", err);
            });
            flySoundStarted = true;
          }

          swatSound.currentTime = 0;
          swatSound.play();
        });

        setInterval(() => {
          if (!gameOver) {
            gameTime -= 1;
            if (gameTime <= 0) {
              gameOver = true;
              flySound.pause();
              flySound.currentTime = 0;
              winSound.pause();
              swatSound.pause();
            }
          }
        }, 1000);

        requestAnimationFrame(gameLoop);
      }

      function gameLoop() {
        ctx.clearRect(0, 0, canvasW, canvasH);

        if (!gameOver) {
          updateFlies();
        }

        let numFlies = getNumFlies();
        for (let i = 0; i < numFlies; i++) {
          if (isFlyAlive(i)) {
            let x = getFlyX(i);
            let y = getFlyY(i);
            ctx.beginPath();
            ctx.arc(x, y, 10, 0, Math.PI * 2);
            ctx.fillStyle = 'red';
            ctx.fill();
            ctx.closePath();
          }
        }

        if (mouseClicked) {
          ctx.beginPath();
          ctx.arc(mouseX, mouseY, 30, 0, Math.PI * 2);
          ctx.fillStyle = 'rgba(0, 255, 0, 0.5)';
          ctx.fill();
          ctx.closePath();

          attemptSwat(mouseX, mouseY);

          let allDead = true;
          for (let i = 0; i < numFlies; i++) {
            if (isFlyAlive(i)) {
              allDead = false;
              break;
            }
          }

          if (allDead) {
            winSound.currentTime = 0;
            winSound.play();
            level += 1;
            gameTime = Math.max(5, startingTime - (level - 1));
            for (let i = 0; i < level; i++) {
              createFly();
            }
          }

          mouseClicked = false;
        }

        ctx.fillStyle = 'white';
        ctx.font = '24px Arial';
        ctx.fillText('Time Left: ' + gameTime, 20, 40);
        ctx.fillText('Level: ' + level, 20, 70);

        if (gameOver) {
          ctx.fillStyle = 'yellow';
          ctx.font = '48px Arial';
          ctx.fillText('Game Over!', canvasW/2 - 100, canvasH/2);
        } else {
          requestAnimationFrame(gameLoop);
        }
      }

      init();
    }
