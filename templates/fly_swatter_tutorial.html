🪰 Fly Swatter Tutorial

This tutorial explains how the Fly Swatter game works:

1. C Code (Compiled to WebAssembly)

  • Stores an array of flies (Fly[] structs)
  • Handles fly movement and bouncing off screen edges
  • Detects collision with your swat (mouse click)

2. JavaScript Code

  • Draws flies onto an HTML5 Canvas
  • Calls the C (WASM) functions using cwrap
  • Manages sounds, timers, and game progression

🧠 Why WebAssembly?

  • C code runs super fast in the browser 🚀
  • Handles math and physics at near-native speed
  • Perfect for games, simulations, or heavy number crunching
