🎮 Game Overview

Blood Factory is a simple top‑down adventure inspired by classic dungeon crawlers. The house map is drawn from a horror tileset, and you control the hero Vladimir as he roams the rooms slaying skeletons. The game logic lives primarily in a C module compiled to WebAssembly using emcc, exposing a handful of functions to JavaScript. Each frame, the JavaScript calls into the WebAssembly module to update the game state and then draws the map, player, and any remaining enemies on a canvas.

🔧 C Driver

The core state of the game—player and enemy positions, movement, attack detection, and win condition—is tracked in C structures. The exported functions provide a minimal interface: 


typedef struct {
    float x, y, vx, vy;
    bool alive;
} Enemy;

float player_x, player_y;
Enemy enemies[MAX_ENEMIES];
int num_enemies;
int kills;
bool game_over;

EMSCRIPTEN_KEEPALIVE
void set_screen_size(int w, int h);

EMSCRIPTEN_KEEPALIVE
void init_game();

EMSCRIPTEN_KEEPALIVE
void update_game(float dt);

EMSCRIPTEN_KEEPALIVE
void move_player(float dx, float dy);

EMSCRIPTEN_KEEPALIVE
void player_attack();

EMSCRIPTEN_KEEPALIVE
float get_player_x();
EMSCRIPTEN_KEEPALIVE
float get_player_y();
EMSCRIPTEN_KEEPALIVE
int get_num_enemies();
EMSCRIPTEN_KEEPALIVE
float get_enemy_x(int index);
EMSCRIPTEN_KEEPALIVE
float get_enemy_y(int index);
EMSCRIPTEN_KEEPALIVE
int is_enemy_alive(int index);
EMSCRIPTEN_KEEPALIVE
int is_game_over();
EMSCRIPTEN_KEEPALIVE
int get_score();

Movement: Vladimir’s position is updated through the move_player function, which clamps his location to the boundaries of the map.
Enemies: Each enemy wanders with a random velocity and bounces off the walls. When Vladimir attacks, any enemy within a fixed radius is marked dead, incrementing the kill counter. Once all enemies are slain, is_game_over returns 1.

💻 JavaScript Glue

The JavaScript file (see static/blood_factory_game.js) initializes the WebAssembly module and wires up input, drawing, and the leaderboard. On each animation frame it:

  • Calls update_game(dt) to advance enemies and check the win condition.
  • Applies movement from held keys via move_player(dx,dy).
  • Reads positions via get_player_x, get_player_y, and iterates over enemies with get_num_enemies etc.
  • Renders the background map and sprite sheets to the canvas.

When the game is over, a prompt allows you to submit your kill count to the leaderboard. Feel free to inspect and modify both the C driver and the JavaScript to add more mechanics, such as health points, items, or multiple rooms!
